Design a modern admin dashboard UI for a travel experience platform called WanderLab.
The platform focuses on authentic travel journals, local experiences, and connections between travelers and local service providers, not mass tourism.

The dashboard should be clean, professional, data-driven, and easy to manage large community content.

Layout

Left sidebar navigation

Top header bar with search, notifications, and admin profile

Main dashboard content area with cards, tables, charts, and moderation panels

Main Sections

1. User & Partner Management

User table with filters and search

Role tags:

Explorer (traveler sharing experience)

Planner (traveler looking for itineraries)

Local Provider (local services)

Account status indicators (active, suspended, pending)

Partner verification panel

Reputation score for local providers

Actions: approve, reject, suspend, verify

2. Content Moderation

Travel journal review panel

Posts displayed as cards containing:

timeline preview

photos/videos

cost breakdown

location tag

Moderation actions:

approve

flag

remove

mark as advertisement

Community report queue

Content authenticity indicator (AI assisted)

3. AI & Data Monitoring

AI system status panel

Visualization of data flow from:

travel journals

search behavior

user preferences

budget data

AI recommendation accuracy monitor

Alerts when recommendations become too “mainstream”

Logs for AI tagging system and itinerary suggestion engine

4. Analytics Overview

Dashboard cards:

New travel journals created

Active users

Platform growth rate

Successful traveler–local provider connections

Charts:

user growth

engagement rate

travel journal activity timeline

Geographic heatmap showing travel activity
