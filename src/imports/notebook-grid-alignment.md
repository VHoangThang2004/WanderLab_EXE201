1. Align Text with the Grid Lines

The text should align perfectly with the notebook grid.

Fix by:

Matching the line height of text to the grid size

Each line of text should sit exactly on one grid row

Example logic:
If the notebook grid height is 24px, set the text line height to 24px so each line fits the notebook lines.

The goal is to make the text feel like natural handwriting on notebook paper.

2. Remove Input Padding That Breaks Alignment

Currently the text fields have padding that pushes the text away from the grid lines.

Fix by:

Removing or reducing top and bottom padding

Making the text start exactly on the grid line

The input field should not float above the grid.

3. Ensure Text Blocks Respect the Grid Structure

All text areas should follow the grid structure of the notebook page.

Adjust:

Vertical spacing

Baseline alignment

Text container height

Text rows must not overlap or cut through grid lines.

4. Avoid Traditional Input Box Styling

The diary interface should not look like a typical form field.

Instead:

Make the text appear directly on the notebook page

Remove heavy input borders

Let the text feel like it is written directly on the paper

This improves the travel journal experience.

5. Maintain Consistent Grid Alignment Across the Page

Ensure that all content placed on the notebook page respects the same grid system, including:

Diary text

Image captions

Location notes

Small descriptions

Everything should feel structured by the notebook grid.

Design Goal

The final result should make the interface feel like writing a real travel diary, where text naturally sits on the notebook lines without overlapping or misalignment.
