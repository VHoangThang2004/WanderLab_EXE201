================================================================================
                    WANDERLAB - THIẾT KẾ DATABASE SCHEMA
================================================================================

Database Engine  : PostgreSQL (qua Supabase)
Encoding         : UTF-8
Collation        : vi_VN

================================================================================
1. ENUMS (Các kiểu dữ liệu liệt kê)
================================================================================
- user_role: 'explorer', 'planner', 'local_provider', 'admin'
- user_status: 'active', 'suspended', 'pending'
- user_plan: 'free', 'starter', 'professional'
- diary_status: 'draft', 'pending', 'published', 'flagged', 'removed'
- privacy_setting: 'private', 'friends', 'public'

================================================================================
2. BẢNG: profiles (Thông tin hồ sơ người dùng)
================================================================================
- id              : UUID (PK, References auth.users(id))
- full_name       : TEXT
- avatar_url      : TEXT
- cover_image_url : TEXT
- bio             : TEXT
- location        : TEXT
- role            : user_role (Default: 'explorer')
- status          : user_status (Default: 'active')
- plan            : user_plan (Default: 'free')
- reputation_score: INTEGER (Default: 0)
- diaries_count   : INTEGER (Default: 0)
- followers_count : INTEGER (Default: 0)
- following_count : INTEGER (Default: 0)
- created_at      : TIMESTAMP WITH TIME ZONE
- updated_at      : TIMESTAMP WITH TIME ZONE

================================================================================
3. BẢNG: diaries (Nhật ký du lịch cá nhân)
================================================================================
- id              : UUID (PK)
- user_id         : UUID (References profiles(id))
- title           : TEXT
- location        : TEXT
- country         : TEXT (Default: 'Việt Nam')
- cover_image_url : TEXT
- duration        : TEXT
- dates           : TEXT
- total_budget    : TEXT
- group_size      : TEXT
- description     : TEXT
- privacy         : privacy_setting (Default: 'public')
- status          : diary_status (Default: 'published')
- likes_count     : INTEGER (Default: 0)
- comments_count  : INTEGER (Default: 0)
- views_count     : INTEGER (Default: 0)
- trust_score     : INTEGER (Default: 0)
- budget_notes    : JSONB (Default: '[]')
- tips            : JSONB (Default: '[]')
- created_at      : TIMESTAMP WITH TIME ZONE
- updated_at      : TIMESTAMP WITH TIME ZONE

================================================================================
4. BẢNG: diary_images (Hình ảnh trong Nhật ký)
================================================================================
- id              : UUID (PK)
- diary_id        : UUID (References diaries(id))
- image_url       : TEXT
- caption         : TEXT
- sort_order      : INTEGER (Default: 0)

================================================================================
5. BẢNG: diary_days (Lịch trình từng ngày của Nhật ký)
================================================================================
- id              : UUID (PK)
- diary_id        : UUID (References diaries(id))
- day_number      : INTEGER
- title           : TEXT
- budget          : TEXT
- activities      : JSONB (Default: '[]')

================================================================================
6. BẢNG: diary_budget_breakdown (Phân bổ chi phí của Nhật ký)
================================================================================
- id              : UUID (PK)
- diary_id        : UUID (References diaries(id))
- category        : TEXT
- amount          : TEXT
- percentage      : INTEGER

================================================================================
7. BẢNG: itineraries (Lịch trình tự tạo / AI)
================================================================================
- id                 : UUID (PK)
- user_id            : UUID (References profiles(id))
- destination        : TEXT
- destination_region : TEXT
- destination_image  : TEXT
- duration           : TEXT
- group_size         : TEXT
- budget_level       : TEXT
- interests          : JSONB (Default: '[]')
- estimated_total    : TEXT
- is_ai_generated    : BOOLEAN (Default: false)
- created_at         : TIMESTAMP WITH TIME ZONE

================================================================================
8. BẢNG: itinerary_days & itinerary_budget_breakdown
================================================================================
- itinerary_days:
  - id              : UUID (PK)
  - itinerary_id    : UUID (References itineraries(id))
  - day_number      : INTEGER
  - title           : TEXT
  - emoji           : TEXT
  - budget          : TEXT
  - activities      : JSONB (Default: '[]')

- itinerary_budget_breakdown:
  - id              : UUID (PK)
  - itinerary_id    : UUID (References itineraries(id))
  - label           : TEXT
  - amount          : TEXT

================================================================================
9. CÁC BẢNG TƯƠNG TÁC (SOCIAL INTERACTION)
================================================================================
- follows:
  - follower_id     : UUID (References profiles(id))
  - following_id    : UUID (References profiles(id))
  - created_at      : TIMESTAMP WITH TIME ZONE

- diary_likes:
  - user_id         : UUID (References profiles(id))
  - diary_id        : UUID (References diaries(id))
  - created_at      : TIMESTAMP WITH TIME ZONE

- diary_bookmarks:
  - user_id         : UUID (References profiles(id))
  - diary_id        : UUID (References diaries(id))
  - created_at      : TIMESTAMP WITH TIME ZONE

- itinerary_bookmarks:
  - user_id         : UUID (References profiles(id))
  - itinerary_id    : UUID (References itineraries(id))
  - created_at      : TIMESTAMP WITH TIME ZONE

- comments:
  - id              : UUID (PK)
  - diary_id        : UUID (References diaries(id))
  - user_id         : UUID (References profiles(id))
  - parent_id       : UUID (References comments(id))
  - content         : TEXT
  - likes_count     : INTEGER (Default: 0)
  - created_at      : TIMESTAMP WITH TIME ZONE
  - updated_at      : TIMESTAMP WITH TIME ZONE

================================================================================
10. TRIGGERS & RPC
================================================================================
- update_updated_at_column(): Tự động cập nhật cột `updated_at` mỗi khi có thay đổi trên bảng `profiles`, `diaries`, `comments`.
- handle_new_user(): Trigger tự động tạo bản ghi trong bảng `profiles` khi người dùng mới đăng ký qua auth.users (Supabase).
- increment_like() / decrement_like(): Cập nhật số đếm likes trên bài viết.
- increment_comment() / decrement_comment(): Cập nhật số đếm comments trên bài viết.
